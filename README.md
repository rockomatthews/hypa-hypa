# HYPA HYPA

HYPA HYPA is a mobile-first Hyperliquid wallet concept for iOS and Android.

The app direction is now based on the supplied comic-style brand reference:

- Bright green stage
- Electric blue framing
- Loud yellow hero blocks
- Hot red alerts and risk states
- Black device shell and contrast base

## Product Wedge

- Buy HYPE
- Stake HYPE
- Track validators and rewards
- Run recurring DCA plans
- Keep builder-code monetization attached to routed orders, not staking alone
- Hold perps behind advanced mode, consent, and region controls

## Stack

- Expo
- React Native
- TypeScript

## Run

```bash
npm start
npm run ios
npm run android
```

## Current Build

- Shared theme and reusable comic-card components
- Branded `HYPA HYPA` app shell
